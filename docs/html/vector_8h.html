Descripción detallada

Contenedor Vector<Traits> (almacenamiento contiguo dinámico).

Vector propio con iteradores forward/backward, ForEach, FirstThat, push_back, ToString y protección por mutex. El nodo se modela con la estructura VectorNode (un valor y un Ref).
