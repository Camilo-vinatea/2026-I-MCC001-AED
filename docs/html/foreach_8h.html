Descripción detallada

Algoritmos genéricos ForEach y FirstThat sobre iteradores.

Funciones plantilla que recorren cualquier par de iteradores aplicando una función (variádica) a cada elemento. Se usan desde los contenedores para definir sus métodos públicos de recorrido.
