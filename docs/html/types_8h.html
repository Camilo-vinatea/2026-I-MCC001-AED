Descripción detallada

Aliases de tipos y tamaños portables para toda la librería.

Define los identificadores de tipo cómodos (TI, TD, TS, Ref, XT) y los tipos empleados por el B-Tree (obj_id_t, tree_order_t, tree_height_t, btree_key_t, btree_pos_t, use_count_t, bree_size_t).
