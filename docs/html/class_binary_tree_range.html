Descripción detallada

template<typename Container, typename Policy>
class BinaryTreeRange< Container, Policy >

Adapta un par begin/end a rango iterable para range-for.

Adquiere unique_lock<mutex> durante toda la iteración.

Atención
No usar dentro de métodos que ya tengan scoped_lock: el mutex no es reentrante (ver toString() en BinaryTree).
